## Qualifications

These measurements use the corrected full-message hash-chain absorption and
explicit verifier success check. Old measurements are not comparable as a
performance-only change. The original proof verifies; modifying the public
challenge or proof bytes is rejected by the regression checks.

The setting uses 92 FRI queries and a nominal 128-bit target; 130.2 bits is
the backend's heuristic estimate, not a tight end-to-end guarantee. Matching
the theoretical BCS transform still requires the compiler-level checks
documented in the paper's Aurora appendix. The verifier executable also
loads an unnecessary local witness fixture, which is not a protocol message.
